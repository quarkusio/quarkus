= Kafka Dev UI
include::_attributes.adoc[]
:summary: Dev UI extension for Apache Kafka for development purposes.
:topics: messaging,kafka,dev-ui,dev-mode
:extensions: io.quarkus:quarkus-kafka-client,io.quarkus:quarkus-messaging-kafka

If any Kafka-related extension is present (e.g. `quarkus-messaging-kafka`),
the Quarkus Dev UI is extended with a Kafka broker management UI.
It is connected automatically to the Kafka broker configured for the application.

image::kafka-dev-ui-link.png[alt=Kafka Dev UI link, width=25%, align=center]

With the *Kafka Dev UI*, you can directly manage your Kafka cluster and perform tasks, such as:

* Listing and creating topics
* Visualizing records
* Publishing new records
* Inspecting the list of consumer groups and their consumption lag
* Viewing, creating and deleting access control lists (ACLs)

image::kafka-dev-ui-records.png[alt=Kafka Dev UI records, width=80%, align=center]

IMPORTANT: Kafka Dev UI is part of the Quarkus Dev UI and is only available in development mode.

== Managing ACLs

The *Access control list* page lists the ACLs defined on the broker: principal, host, operation, permission, and resource (type, name, pattern type).

Use the *Create ACL* icon to add an ACL.
The host defaults to `*`.
Use the *Delete ACL* icon on a row to remove that ACL.

If an operation fails, the page or a notification shows the cause. Typical causes are:

* The broker has no authorizer enabled, so it does not support ACLs.
* The Kafka client lacks permission. Listing ACLs requires `DESCRIBE` on the `Cluster` resource. Creating or deleting them requires `ALTER`.
* The broker rejected the request, for example because of an invalid resource name.
